# 论文与发布实现对照

基线：`67306350a049daf87ef5ac384b367c87d5b349eb`。论文：TACL arXiv 2510.15269v2，公式 7–10。以下为源码静态证据，未作为训练结果验证。

论文使用上下文表示和聚类定义难度，以最近 Macro-F1 的绝对差分构成平均增长与瞬时增长，在 `gamma_latest < beta * gamma_average` 时从 easy 扩展至 easy+middle，再扩展至全量；最终阶段采用耐心早停。公式中的增长是绝对分数差，不是除以前一分数的相对增幅。

## 不应静默修改的现有问题

- ICD checkpoint 不记录课程阶段、分数窗口和采样状态；中断恢复不能声称忠实延续课程。
- TCM v2 最终触发停止的 `break` 位于本轮 checkpoint 保存之前；两份 `modelling_tcm.py` 存在实质差异，未合并。
- Readmission 部分 `best_model` 实际保存最后参数；纯评估流程仍可能依赖新训练的 checkpoint。多个难度脚本具有不同阈值、特征和输出文件，未统一算法。
- ICD 报表所需原始处理语料与课程训练语料名称不同。报表的 `mimiciii_50` 条目使用 `mimiciii_full.feather` 是既有映射，保留并提示。
- 聚类实验的输入 Feather 可能包含多个 split；必须检查 ID 覆盖才能判断是否存在转导使用。当前不能直接断言已发生测试标签泄漏。
- 论文包括院外死亡预测；仅凭当前 `dead/` 片段，不能确认一套完整、与论文匹配的训练评估入口。

## 研究基线的三个层次

1. **Released**：当前发布脚本的原有行为，结构重构保持这一层。
2. **Paper-faithful**：另设实现，显式落实论文的初始阶段、Macro-F1、严格比较、早停和可恢复状态；歧义及选择要预注册。
3. **Proposed**：方案书的新采样策略，独立于上述实现修复比较。

本轮没有把第 2、3 层算法写入现有训练器。修复所增加的性能不能归入新算法贡献。
